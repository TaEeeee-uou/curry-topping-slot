# トッピングスロット / Topping Slot

飲食店でカレーのトッピングを決めるスロットマシン風Webアプリ。単一の `index.html` で動作し、ライブラリ依存はありません。

## 使い方

- `index.html` をブラウザで開くだけで動きます（GitHub Pages などの静的ホスティングにそのまま置けます）
- **スタート** で全列が回り、**ストップ** を押すごとに左から1列ずつ止まります。列を直接タップしても止まります
- 回しっぱなし防止のため、60秒で自動停止します
- 止まった列は **回し直す** で1列だけやり直せます（他の列と重複しません）
- 右上の **トッピングを編集** で候補の追加・ON/OFF・削除、選ぶ数（2〜4）、各言語の名前を設定できます
- 言語は 日本語 / 中文 / English / Bahasa Melayu を切り替えられます

## データの保存

候補・言語・選ぶ数・効果音の設定はブラウザの `localStorage` に保存されます（端末ごと）。

## 開発

```bash
python3 -m http.server 8643
```

で `http://localhost:8643` を開いて確認できます。
